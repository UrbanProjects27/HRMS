# GitHub manual upload package

Upload these files to the matching paths in your GitHub repository, then commit
them from GitHub when you are ready. This package does not include the database
migration; use the separate Supabase SQL file for that.

Files included:

- `app/page.tsx`
- `supabase/functions/manage-attendance-regularization/index.ts`
- `supabase/functions/manage-overtime/index.ts`
- `supabase/functions/mark-attendance/index.ts`
